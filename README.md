# Linux Bash Scripts

Bash scripts written while learning Linux system administration and cloud fundamentals on AWS EC2.

## Scripts
- `greet.sh` — argument handling and input validation
- `backup.sh` — directory backup with tar and existence checks
- `analyze.sh` — nginx log analysis (top IPs, request count) using pipes and functions
- `loop.sh`, `files.sh` — for-loops over lists and files

## Skills practiced
Linux CLI, file permissions, bash scripting (variables, conditionals, loops, functions), pipes, log analysis, Git.
